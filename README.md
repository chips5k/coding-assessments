# Coding Assessments

A curated collection of technical interview solutions and coding challenges.

## Assessments

### [Tax Calculator](tax-calculator) (2017)
Express and React web application for Australian income tax calculation and payslip generation. Implements progressive tax bracket evaluation, repository pattern, and unit tests using Mocha and Jest.

### [Go Booking API](go-booking-api) (2019)
REST API written in Go for managing booking reservations. Features Docker containerization, Elastic Beanstalk configuration, and automated test pipelines.

### [Booking CSV Uploader](booking-csv-uploader) (2021)
React and Express application for parsing CSV bookings, rendering calendar timeline segments, and calculating booking schedule overlaps and conflicts in real time.
