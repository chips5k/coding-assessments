# Tax Calculator

Express and React web application for Australian income tax calculation and payslip generation.

## Features

- **Income Tax Calculation**: Computes progressive tax brackets, gross income, net income, and superannuation.
- **REST API**: Express backend with repository pattern and immutable domain models.
- **React Client**: Single-page frontend for adding payees and generating printable payslips.
- **Automated Tests**: Unit and integration test suite using Mocha and Jest.

## Setup

```bash
# Install server dependencies
yarn install

# Install client dependencies
cd react-client && yarn install
```
